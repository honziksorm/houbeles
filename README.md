# Houbeles

Osobní webová appka na poznávání hub z českých lesů. Funguje offline přímo v telefonu.

Appka: https://honziksorm.github.io/houbeles/

Zdroje: fotky z [iNaturalistu](https://www.inaturalist.org) (licence CC, autoři uvedeni u fotek v atlasu), rozpoznávací model [BioCLIP](https://github.com/Imageomics/bioclip) (MIT), jedlost a znaky z Wikidat (CC0), popisy z české Wikipedie (CC BY-SA), [onnxruntime-web](https://github.com/microsoft/onnxruntime) (MIT), ikony [Tabler](https://tabler.io/icons) (MIT), písma Baloo 2 a Nunito (OFL).

Určení z fotky je jen pomůcka. Nikdy nejez houbu jen podle appky.
